# Nicolò Maffei-Faccioli · Academic website

Open `index.html` to preview the site. The page is static and uses relative paths for its stylesheet. The portrait from the original Google Site is stored in `assets/portrait.jpg`.

## Publish on GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io` for an account homepage, or use another repository name for a project site.
2. Commit the contents of this folder at the repository root on `main`, including the hidden `.nojekyll` file.
3. In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then select **Save**.

GitHub displays the live URL under **Settings → Pages** when deployment finishes. See [GitHub’s publishing guide](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Edit the site

Edit the profile and research entries in `index.html`. The colors, typography, and responsive layout are in `styles.css`. The profile and research scroll as part of one document.
